# Token Workshed 0.2.0 — Developer Preview

Native Mac workbench for local MLX models. Configure an MLX 4-bit quantization
work order, run it, register its result in the local model library, and switch
to chat.

## First launch

The first launch needs an internet connection to bootstrap Python and the
`vllm-mlx` runtime. Model weights are not bundled; choose a cached model or
download one separately before starting a chat or Workshed job.

## Requirements

- macOS 13 or later on Apple Silicon (`arm64`)
- Internet access on first launch to bootstrap Python and `vllm-mlx`
- A separate model download; model weights are not included in the installer

## macOS distribution status

This is a developer preview. The 237 MB installer is unsigned and not
notarized, so Gatekeeper may block it on another Mac. The maintainer has tested
the installation; this does not claim a separate clean-machine test.

## What's new

- A native **Workshed** page for local model-development work orders.
- Editable model, data, quantization, evaluation, and delivery settings, with
  a preflight plan before a run begins.
- MLX 4-bit quantization with managed artifact registration. The demonstrated
  path uses `ibm-granite/granite-4.0-h-350m`; see the
  [end-to-end record](https://github.com/Taylor-He/token-workshed-for-Apple-Sillicon/blob/main/docs/testing/2026-10-08-ui-quantization-e2e.md).
- Clear run status, artifact handling, and configurable parameters for model
  development steps. Step availability is capability-gated by the local
  runner; unsupported operations are not silently substituted.
- A consistent, restrained monochrome style across Chat, Workshed, and
  Terminal.

## Re-published fixes

- Fixed MLX quantization output creation and added preflight checks for missing
  Metal support and already-quantized source models.
- Model registration now checks the saved artifact through the same local
  `vllm-mlx` serving path used by the app.
- Model startup errors include useful diagnostics while redacting common
  credentials from captured logs.
- Hugging Face search results are easier to find and rank, and selected model
  rows now keep readable text on the dark selection background.

## Validation scope

One small-model UI quantization and chat path was exercised locally. This does
not mean every model, training or distillation operation, or control-flow
combination has been validated. Full visual, accessibility, signing, and
notarization acceptance remain open.
