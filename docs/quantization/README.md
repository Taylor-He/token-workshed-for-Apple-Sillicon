# Quantize workbench visual drafts

information density and job emphasis:

3. [Operations-first](caligo-quantize-03-ops.svg) is optimized for remote Worker monitoring and delivery.

The Rust/Iced page follows draft 02 while retaining the remote Worker details
and recovery copy from draft 03.
