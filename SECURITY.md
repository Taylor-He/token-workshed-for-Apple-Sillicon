# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's
[private vulnerability reporting form](https://github.com/Taylor-He/token-workshed-for-Apple-Sillicon/security/advisories/new).

Do not disclose suspected vulnerabilities in public issues, discussions, or
pull requests.

Please include the affected Token Workshed version, macOS version, a description
of the impact, and steps to reproduce the issue. A minimal proof of concept is
helpful when it is safe to provide. Remove API keys, access tokens, personal
data, private prompts, and unrelated local paths from logs or screenshots.

## Scope

Reports are welcome for security issues that affect Token Workshed or
first-party code maintained in this repository, including the application,
installer and bootstrap scripts, and supported integrations. If an issue is
solely in an upstream dependency, macOS, a model, or a third-party service,
please report it to the relevant maintainers as well and explain any
Token Workshed-specific impact.

## Supported Versions

The maintainer prioritizes the latest published release and the current `main`
branch. Reports affecting older releases may require upgrading to a newer
version; fixes for older releases are considered case by case.

## Coordinated Disclosure

Please keep reports private while they are being investigated. The maintainer
will coordinate with the reporter before public disclosure. Response and
remediation times can vary; no fixed response or resolution time is promised.
